# Gotham webfonts (licensed)

Drop the licensed Gotham woff2 files here with these exact names —
`index.html` already declares the matching `@font-face` rules:

- `Gotham-Black.woff2`  (weight 900 — display headlines)
- `Gotham-Bold.woff2`   (weight 700 — labels, buttons, badges)
- `Gotham-Book.woff2`   (weight 400 — body text)

Until they exist, the site falls back to Montserrat (Google Fonts),
which is the closest free substitute.
